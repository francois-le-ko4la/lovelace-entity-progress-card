Test protocol

  1. Automated pass over styles.ts to extract every declaration that could be a compat risk (color-mix(), round(), duplicated declarations inside a keyframe).
  2. Each one adapted here as closely as possible to the real card CSS - same properties, same values, illustrative colors only.
  3. Legacy vs modern declarations reused as-is (not rewritten) to build the comparison swatches, so what you see is the actual shipped CSS, not a paraphrase.
  4. Visually checked against Chromium Version 92.0.4496.0 (Developer Build) (64-bit).
