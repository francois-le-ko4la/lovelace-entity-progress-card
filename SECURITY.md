# Security Policy

## Supported versions

Only the [latest stable release][latest] receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability.

Report it privately through GitHub: [Security → Report a vulnerability][report].

Include the card version, your Home Assistant and browser versions, and the
steps or configuration that trigger the problem. You will get an answer as soon
as possible, and a fix is released once it is confirmed.
